# Pokémon Atlas

**Энциклопедия Pokémon, личная коллекция и игровые гайды.**

### [Открыть Pokémon Atlas](https://lustuwu.github.io/pokemon-atlas/)

На сайте можно:
- Искать покемонов, изучать формы, характеристики, эволюции и способности.
- Смотреть атаки и их эффекты.
- Вести коллекцию по отдельным играм: пойманные покемоны, Shiny, собственные экземпляры и оценка IV.
- Узнавать местонахождение покемонов в играх.
- Проходить **Pokémon Legends: Z-A** с помощью гайда по заданиям, Wild Zones, боссам, TM, предметам и Mega Dimension.
- Собирать команды в экспериментальном конструкторе.

**Как пользоваться:** выбери нужный раздел в меню. В «Гайдах» выбери игру и открой задание или предмет. Выполненные задания можно отмечать галочками.

**Важно:** коллекция и прогресс гайдов сохраняются в браузере на текущем устройстве. Резервную копию коллекции можно экспортировать в JSON. Не все игровые сведения одинаково полны — неизвестные данные помечаются отдельно.

Покемоны и связанные названия принадлежат Nintendo, Game Freak и Creatures. Pokémon Atlas — независимый фанатский проект.
