# Pokémon Atlas — MVP 0.1

Адаптивный фанатский Pokédex (русский интерфейс, английские названия + русская локализация). Работает как статический сайт и может устанавливаться как PWA.

## Запуск за 1 минуту

1. Распакуйте архив в папку `pokemon-atlas`.
2. Откройте терминал в этой папке.
3. Запустите HTTP-сервер:

   ```bash
   python -m http.server 8000
   ```

4. Откройте в браузере **http://localhost:8000**.

Если Python не установлен, можно использовать Node.js с любой простой утилитой HTTP-сервера. Не открывайте `index.html` двойным нажатием через `file://`: браузер может блокировать JS-модули и PWA.

### Как установить на Android

Нужно сперва опубликовать папку на HTTPS-хостинге (например GitHub Pages / Cloudflare Pages / Netlify), открыть полученный адрес в Chrome и воспользоваться пунктом **«Установить приложение»** либо **«Добавить на главный экран»**. На телефоне обычный `http://<IP компьютера>` не является защищённым контекстом для PWA; `localhost` с компьютера также недоступен с телефона без дополнительных настроек.

Кнопка установки в самом сайте появляется, когда браузер считает PWA пригодным к установке. Сайт по HTTPS может работать и без установки.

### Публикация без сборки

Загрузите **содержимое** папки `pokemon-atlas/` в корень статического сайта. `index.html` и `manifest.webmanifest` должны оказаться на одном уровне, `src/` и `icons/` — рядом. Сборка и npm не нужны.

## Уже работает

- Поиск по английскому и русскому названию, а также номеру Национального Покедекса.
- Фильтры по одному или нескольким типам, поколениям I–IX, сортировка по номеру, имени или сумме статов.
- 1025 базовых видов из CSV PokéAPI (после успешной сетевой загрузки); не все формы.
- Карточки: английские и русские имена, типы, поколения, базовые показатели.
- Подробности: характеристики, способности, эволюционная семья.
- Изображения: официальный арт, Shiny, HOME-рендеры, пиксельные спрайты (в зависимости от наличия на сервере).
- Избранное с сохранением в `localStorage`.
- Вкладки «Атаки» (по игре / способу изучения) и «Где найти» (дикие встречи по игре), которые подгружаются по запросу из PokéAPI.
- PWA manifest, Service Worker, кэш приложения, сохранение каталога и ранее загруженных изображений.
- Работа без сети **после успешной загрузки** сохранённых данных (отдельные динамические вкладки и ранее не просмотренные изображения могут требовать интернет).

## Важные ограничения MVP

1. **Первая полная загрузка требует интернет.** Пока она не завершена, работает встроенная **демонстрационная коллекция из 29 покемонов**. Если браузер сохранил полный каталог, он откроется и без сети.
2. `PokéAPI` — сторонний сервис. Сведения зависят от наполнения его базы; особенно для последних игр и DLC есть пробелы.
3. Основные характеристики и типы в каталоге относятся к текущей базовой форме, **не к каждой игре отдельно**. Исторические изменения, региональные и боевые формы требуют отдельного слоя данных.
4. Вкладка атак основана на сведениях PokeAPI о способах изучения и **не является готовым валидатором легальности**. Сейчас названия атак на английском, интерфейс — на русском.
5. Вкладка встреч **не покрывает** все подарки, обмены, эволюции, яйца, рейды и DLC; отсутствие записи не равно невозможности получить покемона.
6. Галерея использует внешние изображения. **Интерактивных 3D-моделей в MVP нет**. HOME — это изображения рендеров, а не 3D-просмотрщик.
7. Данные из публичных GitHub-репозиториев обновляются при запуске. Для стабильной продакшн-версии стоит закрепить версии источников и наладить проверяемый процесс обновлений.
8. Серверных аккаунтов и межустройственной синхронизации ещё нет.

## Источники и авторство

- PokéAPI: https://pokeapi.co/ и https://github.com/PokeAPI/pokeapi
- Pokémon спрайты: https://github.com/PokeAPI/sprites
- Русские имена: https://github.com/sindresorhus/pokemon (MIT лицензия кода набора)

Pokémon и соответствующие персонажи принадлежат Nintendo, Game Freak и Creatures. Это **неофициальный некоммерческий фанатский прототип**, не связанный с владельцами франшизы. Публикация официальных изображений и использование товарных знаков могут требовать отдельных разрешений; статус репозитория исходников не предоставляет автоматически лицензии на графику Pokémon.

├── index.html                 # Страница и семантическая разметка

│   ├── app.js                 # Поиск, фильтры, избранное, модальные карточки

└── docs/
    └── ARCHITECTURE.md       # План дальнейшей разработки
