# Pokémon Atlas

### [Открыть Pokémon Atlas](https://lustuwu.github.io/pokemon-atlas/)

**Pokémon Atlas 0.4** — неофициальный двуязычный Pokédex и справочник атак с экспериментальным конструктором команд. Сайт работает через GitHub Pages: **для использования не нужно скачивать архивы или запускать консоль.**

## Что есть на сайте

- Национальный Pokédex: поиск по номеру и имени, типы, поколения, характеристики, способности, Shiny, эволюции, галерея и избранное.
- База атак: поиск и фильтры; сила, точность, PP, категория и раскрываемый эффект.
- Два варианта языка: **RU/EN** и **EN**. Для 131 атаки и 70 способностей подготовлены русские описания; для остальных показывается русская сводка, если эффект удаётся уверенно распознать. Неизвестные уникальные механики отмечены как требующие ручного перевода и проверки. Английский оригинал доступен при раскрытии карточки. **Это не полный проверенный перевод всех эффектов**; работа над словарём продолжается.
- **Конструктор команд (бета):** выбери 0, 1 или 2 покемонов и при желании зафиксируй им роль. Можно получить варианты на 3–6 покемонов (в Doubles минимум 4). Доступны отдельные прототипы для Gen 9 Singles Casual, OU, UU, Ubers, Doubles OU, National Dex и Pokémon Champions Regulation M-C (Doubles).
- Оценка слабостей, перекрытия типов, роли ловушек, снятия ловушек, скорости, физических/специальных атакующих и синергии погоды; три стратегии «баланс», «атака» и «контроль».
- Вывод билда с четырьмя атаками, предметом, способностью, Nature, EVs и Tera для основных форматов. Кнопка «Копировать в Showdown». Для **Pokémon Champions** используется **66 Stat Points (не EVs), максимум 32 в характеристику**, без Tera и с Item Clause; отдельный текстовый экспорт для ручной настройки команды.

## Важно про бета-версию конструктора

Это **прототип подбора, а не полноценный валидатор и не гарантия побед**. Он допускает выбор любого из 1025 видов Национального Покедекса в свободном режиме, а в соревновательных форматах отсекает неподходящие виды на основе таблиц Pokémon Showdown. Использует проверку списка изучаемых атак, основные ограничения тиров и список Champions M-C. Установлены правила предметов, запрет легендарных в Champions, Item Clause и единственная Mega Evolution. Автоподбор ускорен приоритетным списком из 175 кандидатов; любые допустимые виды можно закрепить вручную. **Это не полный валидатор**: специфические комбинации способностей, форм, переносов атак и сложные бан-листы требуют дополнительной проверки. Для OU, UU и остальных форматов проверяйте итоговый набор в валидаторе [Pokémon Showdown](https://play.pokemonshowdown.com/).

Режим Champions M-C ориентирован на регламент, действующий 09.09–02.12.2026; [официальное описание](https://champions-news.pokemon-home.com/en/page/816.html). Там используются Stat Points, а не привычные EVs.

## Для разработчиков

Проект — статическое PWA (HTML/CSS/JS). Для локального запуска в корне репозитория:

```sh
python -m http.server 8000
```

Затем `http://localhost:8000`. Без локального запуска сайт доступен [по ссылке выше](https://lustuwu.github.io/pokemon-atlas/).

Автоматические тесты:

```sh
node tests/smoke.mjs
node tests/team.mjs
```

Подробности: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

Источники соревновательных правил и learnsets: [Pokémon Showdown](https://github.com/smogon/pokemon-showdown), снимок правил от 04.11.2026. Списки легальности не обновляются автоматически: после изменений регламента их требуется обновить. Сведения об M-C: [официальный регламент](https://champions-news.pokemon-home.com/en/page/816.html).

Данные Покедекса и атак: [PokéAPI](https://pokeapi.co/); изображения: [PokéAPI Sprites](https://github.com/PokeAPI/sprites). Права на Pokémon принадлежат Nintendo, Game Freak и Creatures. Этот проект не связан с правообладателями.
