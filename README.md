# Pokémon Atlas

**A Pokémon encyclopedia, collection tracker, and game guide — all in one place.**

### [Open Pokémon Atlas](https://komasannyan.github.io/pokemon-atlas/)

### Features

- Explore Pokémon, their forms, stats, evolutions, and abilities.
- Browse moves and their effects.
- Track your collection across games, including Shiny Pokémon.
- Find Pokémon locations in supported games.
- Use the **Pokémon Legends: Z-A** guide for missions, bosses, Wild Zones, TMs, items, and Mega Dimension.
- Build teams with the experimental team builder.

**How to use:** Open the website, choose a section, and search for a Pokémon, mission, or item. Check off guide steps as you play.

**Note:** Collection data and guide progress are saved in your browser. You can export a JSON backup of your collection. Some game information is still being expanded.

## Русский

**Pokémon Atlas — энциклопедия покемонов, коллекция и гайды по играм в одном месте.**

### [Открыть Pokémon Atlas](https://komasannyan.github.io/pokemon-atlas/)

### Возможности

- Изучай покемонов, их формы, характеристики, эволюции и способности.
- Просматривай атаки и их эффекты.
- Веди коллекцию по играм, включая Shiny-покемонов.
- Узнавай местонахождение покемонов в поддерживаемых играх.
- Пользуйся гайдом по **Pokémon Legends: Z-A**: задания, боссы, Wild Zones, TM, предметы и Mega Dimension.
- Собирай команды в экспериментальном конструкторе.

**Как пользоваться:** Открой сайт, выбери раздел и найди нужного покемона, задание или предмет. По мере прохождения отмечай выполненные шаги.

**Важно:** Коллекция и прогресс гайдов сохраняются в браузере. Коллекцию можно экспортировать в JSON. Некоторые сведения об играх ещё дополняются.
