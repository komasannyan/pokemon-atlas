# Pokémon Atlas

[**Открыть Pokémon Atlas**](https://lustuwu.github.io/pokemon-atlas/)

**Версия 0.8** — неофициальная Pokémon-энциклопедия, работающая как сайт и устанавливаемое PWA.

## Возможности

- Национальный Pokédex: поиск, поколения, фильтры типов, изображения, Shiny, избранное и описания.
- **0.8 — формы Pokémon:** переключение между разновидностями (включая региональные, Mega и другие формы, представленные в PokéAPI), отдельные базовые характеристики, типы, способности, изображения и Shiny.
- **0.8 — эволюции:** полные ветви эволюционных цепочек с условиями (уровень, предмет, дружба, время, известные атаки и др.).
- **0.8 — история:** отображение доступных в PokéAPI исторических изменений базовых характеристик, типов и способностей по поколениям.
- Базы атак и способностей; русский/английский интерфейс.
- Коллекция по играм и DLC, личные экземпляры, Shiny, примерная оценка IV, экспорт/импорт JSON.
- Экспериментальный конструктор команд с форматами и набором проверок легальности.

## Важно о данных

Показываются **разновидности и исторические сведения, присутствующие в PokéAPI**. Их нельзя считать проверенной полной историей всех форм и каждого поколения: некоторые косметические и игровые формы не представлены отдельными разновидностями, а доступность в отдельных играх зависит от релиза и условий.

Эволюционные условия показывают записи источника, но правила могли изменяться между играми. Раздел местонахождения также пока не охватывает все способы получения: обмены, переносы и события могут быть неполными. Не все эффекты атак имеют проверенный русский перевод.

## Использование

Приложение открывается [по ссылке](https://lustuwu.github.io/pokemon-atlas/), Python для обычного использования не нужен. Для локальной разработки можно запустить `python -m http.server 8000` и открыть http://localhost:8000.

Тесты новых механизмов: `node tests/pokedex-extended.test.mjs`.

Данные сохраняются в браузере. Перед очисткой данных сайта сделайте резервную копию коллекции через её экспорт JSON.
