# Pokémon Atlas

[**Открыть Pokémon Atlas**](https://lustuwu.github.io/pokemon-atlas/)

**Версия 0.9** — неофициальная Pokémon-энциклопедия, работающая как сайт и устанавливаемое PWA.

## Возможности

- Национальный Pokédex: поиск, поколения, фильтры типов, изображения, Shiny, избранное и описания.
- **0.8 — формы Pokémon:** переключение между разновидностями (включая региональные, Mega и другие формы, представленные в PokéAPI), отдельные базовые характеристики, типы, способности, изображения и Shiny.
- **0.8 — эволюции:** полные ветви эволюционных цепочек с условиями (уровень, предмет, дружба, время, известные атаки и др.).
- **0.8 — история:** отображение доступных в PokéAPI исторических изменений базовых характеристик, типов и способностей по поколениям.
- **0.9 — местонахождение каждого Pokémon по играм:** в карточке есть матрица 38 основных игр с региональными Pokédex, известными встречами из PokéAPI и честными пометками о пробелах данных. По Legends: Z-A имеются 20 Wild Zones с временем суток, условием открытия и отдельными проверенными деталями для части видов; отсутствие процента не заменяется выдуманным значением.
- **0.9 — гайды:** выбор всех 38 игр (другие пока не заполнены); для Pokémon Legends: Z-A — 42 основных миссии с рекомендациями, перечень 119 побочных заданий, в том числе 29 с индивидуальными инструкциями, 20 зон, 97 записей о TM, Mega Stones и ресурсы; Mega Dimension — 14 сюжетных и 16 подробно описанных побочных заданий. Поиск и отдельный прогресс выполнения.
- Базы атак и способностей; русский/английский интерфейс.
- Коллекция по играм и DLC, личные экземпляры, Shiny, примерная оценка IV, экспорт/импорт JSON.
- Экспериментальный конструктор команд с форматами и набором проверок легальности.

## Важно о данных

Показываются **разновидности и исторические сведения, присутствующие в PokéAPI**. Их нельзя считать проверенной полной историей всех форм и каждого поколения: некоторые косметические и игровые формы не представлены отдельными разновидностями, а доступность в отдельных играх зависит от релиза и условий.

Эволюционные условия показывают записи источника, но правила могли изменяться между играми. **Матрица местонахождения** — не полная проверенная база всех способов получения во всех играх. Запись в региональном Pokédex сама по себе не доказывает возможность самостоятельной поимки. Встречи из PokéAPI могут не включать обмены, подарки, специальные появления, перенос и DLC. Для Legends: Z-A проверенный список зон не покрывает все точные точки появления и проценты. В гайде для Z-A большая часть побочных заданий имеет ссылку на источник, но ещё не имеет собственной полной пошаговой инструкции; весь DLC side-миссий №120–200 пока также не детализирован. Сохраняемые галочки хранятся локально в браузере. Не все эффекты атак имеют проверенный русский перевод.

## Использование

Приложение открывается [по ссылке](https://lustuwu.github.io/pokemon-atlas/), Python для обычного использования не нужен. Для локальной разработки можно запустить `python -m http.server 8000` и открыть http://localhost:8000.

Тесты новых механизмов: `node tests/pokedex-extended.test.mjs`.

Данные сохраняются в браузере. Перед очисткой данных сайта сделайте резервную копию коллекции через её экспорт JSON.

[Архитектура](docs/ARCHITECTURE.md) · [PokéAPI](https://pokeapi.co/docs/v2) · [Sprites](https://github.com/PokeAPI/sprites)

Pokémon Atlas — фанатский проект, не связанный с Nintendo, Game Freak или Creatures.
