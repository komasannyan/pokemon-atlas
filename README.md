# Pokémon Atlas

### [Открыть Pokémon Atlas](https://lustuwu.github.io/pokemon-atlas/)

**Pokémon Atlas 0.6.1** — неофициальная Pokémon-энциклопедия (PWA), которая работает в браузере и может устанавливаться на телефон. Для посещения сайта не нужно запускать Python.

## Что доступно

- Национальный Покедекс, поиск и сортировка, карточки, характеристики, эволюционные семьи, Shiny-арт и избранное.
- **Случайный покемон на главном плакате при открытии/перезагрузке**, номер, английское имя и вид (genus) из PokéAPI.
- **База атак**, в том числе сортировка по силе от меньшей к большей и обратно (атаки без численной силы расположены внизу).
- **База способностей** с поиском, поколением, эффектом и полным списком носителей по PokéAPI с пометкой первой, второй и скрытой способности.
- **Русский режим**: переведённые вручную эффекты (131 атака, 70 способностей) и **перевод остальных описаний по запросу** через внешний сервис; английский оригинал доступен для проверки.
- **Список основных игр в карточке Pokémon**: известные места встреч и отдельные пометки, где PokéAPI данных не даёт.
- Экспериментальный конструктор команд с разделением форматов, правилами допустимости и экспортом.
- Полностью английский интерфейс (EN), помимо смешанного RU/EN.

## Что ещё не закончено (важно)

**Нет полного проверенного русского офлайн-словаря всех эффектов.** Для непереведённых записей приложение обращается к общественному сервису машинного перевода при открытии карточки и запоминает перевод в браузере. При отсутствии сети, ограничении сервиса или сбое перевод недоступен; это явно сообщается пользователю. В редких механиках автоматический перевод может быть неточным. Записи на русском не следует считать официальной локализацией.

**Нет полной базы способов получения во всех играх.** PokéAPI не включает все рейды, подарки, переносы, обмены и DLC. В интерфейсе перечислены все 38 основных версий, но отсутствие записи о дикой встрече — *не доказательство отсутствия покемона в игре*. Для полного покрытия нужна отдельная база по каждой игре.

**Конструктор пока экспериментальный** и не заменяет валидатор турнира. Исторические изменения атак и форм могут быть представлены неполно.

## Для разработчиков

В корне проекта запустить `python -m http.server 8000`, затем открыть `http://localhost:8000`. Хостинг: GitHub Pages, исходники — в текущем репозитории.

Тесты: `node tests/team.mjs` и `node tests/atlas-06.mjs`.

Источники данных: [PokéAPI](https://pokeapi.co/), [PokeAPI/sprites](https://github.com/PokeAPI/sprites), [Pokémon Showdown](https://github.com/smogon/pokemon-showdown). Перевод непроверенных описаний производится через внешний сервис [MyMemory](https://mymemory.translated.net/).

Pokémon — собственность соответствующих правообладателей. Проект не связан с Nintendo, Game Freak или Creatures.


## Исправление локализации 0.6.1

- Добавлены самостоятельные русские объяснения для **всех 314 способностей основной серии**,
  присутствующих в таблице PokéAPI на дату выпуска. Они не требуют внешнего сервиса
  перевода и сразу появляются в карточках покемонов и базе способностей.
- Убрана заглушка «Уникальная способность покемона…»; для неизвестных и нестандартных
  способностей остаётся загрузка исходного текста.
- Обновлён PWA-кэш. После установки версии 0.6.1 браузер не должен подмешивать
  устаревший файл эффектов.
- Остальные эффекты атак ещё покрыты лишь частично: в этом исправлении не заявляется
  полный проверенный перевод атак.
