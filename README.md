# Pokémon Atlas

**[Открыть Pokémon Atlas](https://lustuwu.github.io/pokemon-atlas/)**

Интерактивная энциклопедия Pokémon — сайт и устанавливаемое PWA. **Чтобы пользоваться приложением, не нужно скачивать файлы или запускать консоль:** откройте ссылку выше.

**Версия 0.2:** Национальный Покедекс, база атак, поиск и фильтры, характеристики, Shiny-изображения, записи Покедекса, описания способностей и эффектов атак, переключатель **RU/EN ↔ EN**, избранное.

> Pokémon Atlas — неофициальный фанатский проект. Не связан с Nintendo, Game Freak или Creatures.

## Что работает

- Поиск покемонов по номеру, английскому или русскому названию, фильтрация по типам и поколениям.
- Карточки с характеристиками, способностями, эволюцией, изображениями, атаками и местами встреч (в пределах данных API).
- База атак: тип, физическая/специальная/статусная категория, сила, точность, PP; раскрывающееся описание эффекта.
- Раскрывающиеся описания способностей и атак в карточках покемонов.
- Переключение языка интерфейса: смешанный русский/английский или английский.
- Избранное и частичный офлайн-доступ после загрузки данных.

## Ограничения

- Внешние источники: [PokéAPI](https://pokeapi.co/) и [PokéAPI Sprites](https://github.com/PokeAPI/sprites). Часть эффектов доступна только на английском.
- Исторические характеристики атак, все формы, DLC и способы получения по играм покрыты не полностью.
- Конструктор команд, полные гайды и интерактивные 3D-модели запланированы, но пока не реализованы.
- Изображения Pokémon защищены правами соответствующих правообладателей.

## Локальный запуск для разработчиков

В корне проекта (где находится `index.html`) выполните:

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000. Опубликованная версия всегда доступна [по ссылке](https://lustuwu.github.io/pokemon-atlas/) без локального запуска.

Проверка данных: `node tests/smoke.mjs`.

Техническая архитектура: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
